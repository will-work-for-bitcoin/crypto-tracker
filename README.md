Real-time cryptocurrency price tracker CLI with live updates, JSON/CSV export, and beautiful terminal output. Zero dependencies.

## Installation

```bash
git clone https://github.com/will-work-for-bitcoin/crypto-tracker.git
cd crypto-tracker
```

## Usage

```bash
python crypto_tracker.py
python crypto_tracker.py --help
```

## Features

- Pure Python 3.7+, zero dependencies
- JSON/CSV export support
- Beautiful terminal output
- Easy to extend and customize
